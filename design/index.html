Read the screen decisions ↓

A reference for the real build.

The approved pilot spec owns behavior. This design makes that behavior easier to understand.

Map

Samples sit above a quiet basemap. The filters only change what is shown. A pin opens the same details as its list row.

  • Keep attribution above all anchored controls.
  • Explain that unsampled areas have no rating.
  • Keep Readings available when tiles fail.

Readings

A scan-friendly list puts connection, rating, value, and time first. Location is secondary and always explicit.

  • Newest captured sample appears first.
  • Filter selection follows you between views.
  • Every saved sample has a details view.

Recording

Explain location at the moment it is needed. Show progress, preserve a valid signal without a pin, and confirm only after saving.

  • One active operation across both views.
  • Retry save reuses the same candidate.
  • Show saved reading reveals a hidden type.
